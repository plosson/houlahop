Copycat

Browsers can only copy text and still images. Copycat copies the real file, so a GIF stays animated and a video stays a video when I paste it.

Download for MacmacOS 14 or later · signed and notarized

How it works

It runs in the menu bar. It only acts when a site I allowed asks it to.

Press Copy on a pageThe page asks Copycat to copy a file by its URL.
Allow the site onceCopycat asks me the first time. Sites I didn't allow can't use it.
Paste anywhereMessages, Slack, WhatsApp, Mail. The GIF or video arrives as a real file.
Add a Copy button to a site 
<script src="copycat.js"></script>

if (await Copycat.status() !== "absent") {
  await Copycat.copy("https://example.com/cat.gif", { name: "cat.gif" })
}
